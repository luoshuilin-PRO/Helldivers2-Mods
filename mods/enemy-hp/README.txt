敌人 HP 菜单版
在舰船或任务中进入菜单，开启/关闭显示。默认开启。
保留原版行为：标记敌人（红色标记）后显示名称及当前/最大 HP，不是显示所有敌人血条。
关闭立即隐藏已显示的标签并停止标记扫描。重新开启后可再次标记敌人。
日志：%LOCALAPPDATA%\Hd2EnemyHp（沿用原模组）。

安装：关闭游戏，在 Arsenal 导入此 ZIP，替换/停用相应旧版本。
同时启用 Mod Options Menu v1.1 和 Bingus Shared Loader v18+，Loader 放在加载顺序底部，Purge → Deploy 后启动游戏。
如果已有 Megapack 提供菜单，只使用一份 Mod Options Menu。
进入 ESC → MODS（模组），修改后点 APPLY 或按 Tab 应用，菜单会保存，下次启动读取。
保存位置：%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\ModOptionsMenu.values。
未安装菜单或注册失败时，本模组暂停功能。两个 SC 插件不需要安装。
沿用附带原包的 build 25480438 校验，其他游戏构建会拒绝运行；本次没有更新游戏版本支持。
已完成隔离脚本检查，游戏内显示与效果未实测。单人/私人使用。源码附在 Source 文件夹。
